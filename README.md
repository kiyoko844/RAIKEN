# RAIKEN® — Personal Progression System (v11)

Личное приложение прогресса: задачи, XP, 100 рангов, медали и достижения, серии, дисциплина.
Чистый HTML/CSS/JS, без сборки. Данные хранятся только в твоём браузере.

## Запуск и публикация
- Локально: открой `index.html` (для PWA и офлайн-режима нужен http/https, например GitHub Pages).
- GitHub Pages: загрузи содержимое папки в репозиторий и включи Pages. Шрифты и GSAP лежат в проекте (`fonts/`, `js/vendor/`), интернет для работы не нужен.
- Установка как приложения: в Chrome/Edge «Установить RAIKEN» (manifest + service worker).

## Горячие клавиши
`N` или `Ctrl+K` — новая задача, `Esc` — закрыть окно.

## Структура
Приложение без сборки: обычные скрипты подключаются в `index.html` в строгом порядке и делят общую область видимости (как раньше делил один `app.js`).

```
index.html            порядок подключения скриптов (порядок важен)
sw.js, manifest       офлайн и установка как приложения
css/                  fonts, variables (палитра по умолчанию), themes (8 тем), base, ice, frames, look
js/core/              config (константы), utils, ranks (формулы), state (S, загрузка, сохранение),
                      engine (XP, серии, штрафы), scheduler (проверка просрочек)
js/data/              awards-data (84 достижения, 52 медали)
js/features/          tasks, goals, quests, calendar, awards, discipline, ranks, profile, backup,
                      rituals, review, insights  — по одной функции «..Html()» на раздел страницы
js/ui/                ice (IndexedDB, обновление DOM), frames (31 рамка), ambient (живой фон),
                      themes (каталог тем), assets, modals, fx, render, events
js/boot.js            запуск
```

Как добавить новый раздел: создай `js/features/<имя>.js` с функцией `<имя>Html(c)`, подключи файл в `index.html` перед `ui/render.js` и добавь вызов в `render()` (`js/ui/render.js`). Общие данные страницы (ранг, даты календаря, выбранный день) приходят в `c` из `viewContext()`.

## Новое в v5
- **Ритуалы** (раздел сразу под шапкой): ежедневные привычки без дедлайнов и штрафов. Сложность Лёгкий/Средний/Сложный даёт +20/+40/+60 XP, выполнение всех ритуалов дня (минимум двух) — бонус +50 XP. У каждого ритуала своя серия и 7 точек последней недели. Отметку можно снять в тот же день: XP возвращается.
- **Итоги**: Сегодня / Вчера / Неделя / Прошлая неделя. Задачи, XP, ритуалы, просрочки, сравнение с прошлым периодом, график XP по дням, короткие выводы и план на завтра. По понедельникам открывается итог прошлой недели.

## Порядок страницы (v6)
Главная → Ритуалы → Сегодня (задачи и испытания) → Долгосрочные цели → Календарь → Итоги и аналитика → Недельный обзор → Достижения, медали и журнал XP → Дисциплина. Тот же порядок в меню слева.

## Что нового в v6
- **Календарь** (структура «задачи × дни» сохранена): липкая шапка и левая колонка, итог дня внизу (выполнено/всего), мини-полоска нагрузки под каждой датой, подсветка «крестом» при наведении, выделение сегодняшнего столбца, фильтры (Все / Важные / Долгосрочные / Просроченные), счётчик выполнения у повторяющихся задач, плитка «Просрочено», легенда обозначений.
- **Итоги и аналитика** — один блок вместо двух: день, неделя, месяц, год. Вверху обзор «сколько сделано сейчас» по всем четырём периодам, ниже — выбранный период со стрелками по истории, кольцо выполнения плана, задачи, XP, ритуалы, просрочки со сравнением с предыдущим периодом, график (XP / Задачи / Ритуалы) по дням или месяцам и короткие выводы.
- Старая панель «Статистика выполнения» удалена: её расчёт (доля выполненных задач в плане периода) теперь кольцо в «Итогах».
- Журнал XP хранит до 5000 последних событий (было 1500), чтобы годовая статистика была полнее.

## Что нового в v7: недельный обзор
Карточка под «Итогами»: цифры недели, три вопроса (что получилось, что мешало, что изменить), оценка самочувствия от 1 до 5 и фокус следующей недели. В пятницу–воскресенье приложение предлагает обзор текущей недели, в понедельник–среду — прошлой (если она была активной и ещё без обзора). Чип «Обзор недели» с точкой появляется в шапке, а выбранный фокус показывается там всю следующую неделю. За первый обзор недели даётся +60 XP; правка и удаление XP не меняют. В карточке: серия недель с обзором, график самочувствия, история записей. Записи сохраняются при «Сбросе всего прогресса».

## Что нового в v9: темы персонажей, рамки и живой фон
Окно «Оформление» открывается чипом с названием темы в шапке, кнопкой «Стиль» у аватара или клавишей `T`. Три вкладки:
- **Темы** (8): Рукия Кучики (лёд), Бьякуя Кучики (сакура, Сенбонзакура), Рэцу Унохана (кровавый банкай), Урахара Кисукэ, Айдзен Сосукэ, Наруто Удзумаки (путь Хокаге), Гатс (Берсерк), Ёруичи Сихоин. Тема меняет всю палитру, а переключатель «Менять рамку вместе с темой» подбирает фирменную рамку персонажа.
- **Рамки** (31): 19 персонажных (лепестки, бабочки, листья, кровь, снег, искры, молнии, спирали, трещины) и 12 универсальных. Фильтр по персонажу, наведение показывает движение.
- **Фон**: живой фон у каждой темы свой (снег, лепестки с порывом Сенбонзакуры, кровавая дымка, светлячки, бабочки, листья Конохи с искрами чакры, пепел и угли, молнии и росчерки). Выключатель и плотность (мало, нормально, много).

Фон ставится на паузу в фоновой вкладке и полностью выключен, если в системе включено «Уменьшить движение». Выбор темы сохраняется и применяется ещё до загрузки скриптов, без вспышки.

Как добавить тему: палитра в `css/themes.css`, запись в `js/ui/themes.js`, система частиц в `js/ui/ambient.js`. Как добавить рамку: запись в `FRAMES` (`js/ui/frames.js`) и палитра `.fr-<id>` в `css/frames.css`.


## Новое в v11
- Рекорд XP пересчитывается после отмены выполнения и удаления задачи: отменённая награда больше не поддерживает ложный рекорд.
- Список задач на выбранный день стал единым: обычные, важные, быстрые, долгосрочные и привязанные к целям отображаются вместе с отдельными метками важности, горизонта и цели.
- В календаре убраны переключатели-фильтры задач. Все категории видны одновременно, а тип и важность указаны рядом с названием.
- Выполненные обычные задачи по-прежнему скрываются из календаря и списка, но остаются в итогах и аналитике.
